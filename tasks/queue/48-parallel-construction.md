Task: construction placeholder on the ground, and an optional game-modification setting for simultaneous construction.
Product requirements from the user (playtest feedback, refined):
1. Production queue semantics stay as the original (as currently on develop: construction and units share one active item per town; units train serially). By default nothing changes in how many items progress at once.
2. At the moment the build command is executed the construction placeholder must be spawned on the ground at the chosen spot, as in the original game (the footprint is reserved and visible immediately, in its first construction stage, before the item becomes active in the queue); cancel removes it and refunds according to the existing refund rule.
3. Add a game-modification settings mechanism ("modifications" / game parameters) that holds clone-only options that intentionally differ from the original. It needs: a persisted settings file next to the other engine options, command-line parameters (for example --mod parallel_construction=on), and an in-game menu entry "Game modifications" listing each option with a short description and an on/off toggle (English UI text; the menu must be reachable from the existing options/pause menu). Options never change anything unless enabled, are part of the replay and save metadata so replays and saves stay deterministic, and are included in the state hash inputs where they affect simulation. Multiplayer lockstep must reject mismatching modification sets.
4. First option: parallel_construction (default off). When on, any number of buildings may be under construction at the same time, each progressing independently, while unit training stays one active item per town. Payment, cancellation refunds, pause, placement reservation, AI use of the queue, save and replay must stay consistent and deterministic in both modes.
Document the modification mechanism and the first option in docs/ (for example docs/modifications.md) and record in docs/engine_rules_status.md which behaviour is original (evidence label V/M/P) and which is a modification.
