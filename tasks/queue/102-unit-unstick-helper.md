Task: units must not get stuck (player feedback), as a switchable helper.
The player reports that units get blocked in forests and in narrow passages and are hard to free even manually. Even if the original behaves like that, it is not acceptable in the enhanced profile; the faithful profile keeps the original behaviour for measurements. Add the modification unit_unstick (default off in the faithful profile, on in the enhanced profile; until profiles exist default off).
Implement in the mover and path code (src/engine/sim/path): stall detection (a unit that has an order but makes no progress for a few ticks), a bounded local repath around the blocker, swapping places with an idle friendly unit that blocks a one-tile passage, sidestepping out of a passage for a moving friendly unit, preferring a route through the passage instead of a detour only when it is free, and a guarantee that a unit never stays stuck forever (after a timeout it is moved to the nearest free tile and the order resumes). Keep the shared determinism: the result must depend only on the simulation state and a fixed tick-seeded choice.

Report for each scenario the arrival ticks and stall counts with the helper off and on; with the helper off all existing movement hashes stay unchanged.
